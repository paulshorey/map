GeoNames centroid seed data for the POI ingestion pipeline.

Files:

- `cities500.txt` and `cities500-readme.txt`: GeoNames cities with population >= 500.
- `countries360-2024.csv`: country centroids from the same GeoNames-derived reference set.

GeoNames data is licensed CC-BY 4.0. For the POC, this repo records attribution metadata
and uses the data as an internal centroid/reference dictionary for normalization.
